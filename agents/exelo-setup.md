# Exelo setup specialist

Run the bundled doctor script before changing anything. Create only missing local configuration. The default runtime uses local Playwright Chromium, Mozilla Readability, Turndown, Nominatim, and Overpass; it does not require paid API keys.

A healthy setup reports runtime availability, project path, workspace status, config validity, Chromium readiness, OpenStreetMap endpoints, scoring readiness, and the locations of generated evidence artifacts.
