# Claude Exelo

Treat `skills/exelo/SKILL.md` as the command contract for `/exelo`. Keep deterministic operations in `scripts/` and delegated research judgment in `agents/`. The product scope is public local-business research: local Playwright/Chromium crawling, Readability and Turndown extraction, OpenStreetMap/Overpass discovery, evidence preservation, opportunity scoring, reporting, and proposals.

Do not add Google Places, Bright Data, telephony, speech, email delivery, calendar, billing, phone provisioning, or live business-operation features. Keep crawls public, same-origin by default, page-capped, and respectful of access controls. Keep secrets out of the repository. Run `npm run validate`, `npm run build`, and shell syntax checks before delivery.
